# Brasa

Corredor sin fin: salta, deslízate y encadena combos.

**Jugar:** https://jeronimoguzman944-spec.github.io/brasa/

Si esa URL da 404, activa Pages una vez:

1. Abre [Settings → Pages](https://github.com/jeronimoguzman944-spec/brasa/settings/pages)
2. Source: **Deploy from a branch**
3. Branch: **main**, folder: **/ (root)**
4. Save

En ~1 minuto el juego queda en el enlace de arriba.

- Toca o barra espaciadora para saltar
- S, flecha abajo o desliza para agacharte
- Las rampas aceleran; el récord se guarda en el navegador
